## ⚙️ 게임 엔진 (기술 스택)

| 파트 | 기술 |
|---|---|
| 🧠 서버 `backend/` | Java 25 · Spring Boot 4.1 · Spring Security · JPA · Flyway · WebSocket(STOMP) |
| 🎨 화면 `frontend/` | React 19 · TypeScript · Vite · Tailwind CSS · TanStack Query |
| 🗄️ DB | PostgreSQL 18 |

### 🌐 서버 배치 (배포)

```
 [ 플레이어 ] ──https──▶ [ Render 무료 · 싱가포르 ]  화면 + 서버 (Docker, 512MB)
                              │            │
                              ▼            ▼
              [ Neon · 싱가포르 ]      [ Supabase Storage · 서울 ]
                 PostgreSQL              사진 · 영상 · 업로드 파일
```

- GitHub `main`에 푸시하면 **자동 배포** (`render.yaml`, `Dockerfile`)
- 운영 설정: `backend/src/main/resources/application-prod.yml` (비밀 값은 Render 환경 변수로만)
- 시드 사진 올리기: `deploy/upload-seed-media.mjs`

## 💾 로컬에서 플레이 (개발 모드)

**준비물:** JDK 25 · Node.js 24 · Docker Desktop (실행 중)

```powershell
# 0) 시드 사진 약 1,450장 받기 (처음 한 번, 약 5분·340MB, Openverse CC0)
#    건너뛰면 사진 대신 그라데이션 그림
node seed-media/download.mjs

# 0-1) 가짜 릴스 영상 100개 만들기 (처음 한 번, 약 5분·180MB). 건너뛰면 릴스 없이 시작
cd backend; .\gradlew reelClips; cd ..

# 1) 서버 (http://localhost:8080) — DB 컨테이너를 자동으로 띄우고, 비어 있으면 가짜 데이터 생성(약 30초)
cd backend
.\gradlew bootRun

# 2) 화면 (http://localhost:5173)
cd frontend
npm install   # 처음 한 번
npm run dev
```

http://localhost:5173 → **"가짜 계정으로 바로 둘러보기"**

## 📖 공략집 (알아 둘 것)

- 🔌 개발 DB는 **5433** 포트, **이 PC 안에서만** 접속됩니다 (5432는 다른 프로젝트가 사용).
- 🔒 로컬 서버는 **127.0.0.1:8080**에서만 받습니다 (Lab의 비밀번호 없는 계정 전환 때문).
- 🧹 DB 끄기: `docker compose down` (데이터 유지) · 데이터까지 지우기: `docker compose down -v`
- 🖼️ 업로드 파일은 로컬에선 `storage/uploads/`, 배포에선 Supabase에 저장됩니다.
- 🚫 이 PC의 보안 정책(Application Control) 때문에 `npm run lint`(oxlint)는 실행되지 않습니다. 타입 검사와 빌드는 정상.
- 🔁 백엔드 라이브러리가 바뀌면 `gradlew bootRun`을 다시 켜야 합니다 (코드만 바뀌면 자동 재시작).
